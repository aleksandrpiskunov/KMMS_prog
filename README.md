# KMMS_prog

A collection of C++ assignments and projects developed as part of the **Modern methods of programming** course at **SPbU**.

## Projects

- **LongNumbers** — working with long numbers.
- **Menu** — implementing menus using classes.
- **Vector List** — working with containers and lists.
- **CMake Menu** — building a project with CMake.
- **Mario OOP** — applying object-oriented programming principles in a Mario project.
- **Mario Refactoring** — refactoring and improving code structure.
- **Qt Keyboard** — handling keyboard input in Qt.
- **Module App** — developing a modular application.

## Technologies

C++, Qt, CMake, Git.
